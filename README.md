# Топ дебетовых карт с кэшбэком 2026

Статический лендинг под финансовую витрину с 5 банками:

- T-Bank
- Альфа-Банк
- ВТБ
- Ozon Банк
- ОТП Банк

## Что внутри

- `index.html` — готовая структура лендинга
- `styles.css` — дизайн и адаптив
- `script.js` — конфигурация кнопок и анимации

## Как вставить свои реферальные ссылки

Откройте `script.js` и заполните поле `referral` для нужного банка:

```js
tbank: {
  referral: "https://ваша-партнерская-ссылка",
  official: "https://www.tbank.ru/cards/debit-cards/tinkoff-black/"
}
```

Если `referral` оставить пустым, кнопки будут вести на официальную страницу банка.

## Как запустить

Достаточно открыть `index.html` в браузере.

## Важно

Контент на странице уже дополнен дисклеймером, но для финансовой ниши условия лучше перепроверять регулярно:

- перед запуском рекламы
- после смены месяца
- при обновлении акций и лимитов у банков
