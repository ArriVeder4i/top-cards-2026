# Топ дебетовых карт с кэшбэком 2026

Статический лендинг под финансовую витрину с 5 банками:

- T-Bank
- Альфа-Банк
- ВТБ
- Ozon Банк
- ОТП Банк

## Что внутри

- `index.html` — готовая структура лендинга
- `styles.css` — дизайн и адаптив
- `script.js` — конфигурация кнопок и анимации


## Как запустить

Достаточно открыть `index.html` в браузере.
